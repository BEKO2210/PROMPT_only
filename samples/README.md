# samples/ — Redacted Sample Outputs

These are realistic worked examples of what each prompt actually
produces. Use them to:

1. **Evaluate the library before buying / committing** — see what
   the agent will deliver, not just what it claims.
2. **Calibrate clients** — show prospects what a deliverable looks
   like during a sales conversation.
3. **Onboard the agent** — paste a sample alongside the prompt so
   the agent has a concrete reference for output shape.

## A note on realism

All companies, people, repositories, financials, and metrics in
these samples are **fictional**. Names like "Acme", "Nordstern Bank",
"Verdant Health" are placeholders. Numbers are realistic but
fabricated. Do not cite these samples as real engagements.

The samples DO reflect realistic engagement output shape, structure,
language, and length.
