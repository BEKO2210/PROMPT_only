# YOUTUBE-SCRIPT — Long-Form YouTube Video Script (verkaufbares Deliverable)

Produces a complete YouTube long-form (8–20 min) script from a topic
brief: hook, structure, B-roll cues, on-screen text suggestions, CTA,
title + description + tags + thumbnail concept. Built around 2026
algorithm reality: retention curve matters more than view count.

**Realistic engagement price: €500 – 2 500 per script.** Often
recurring (€2 000 – 10 000/month for weekly creators).

---

## How to use

Paste the block below, then on the next line:

    CHANNEL: <channel name, niche, audience, voice>
    TOPIC: <what the video covers — be specific>
    TYPE: <TUTORIAL | EXPLAINER | LISTICLE | OPINION | INTERVIEW | STORY | DEMO>
    LENGTH: <target minutes — 8–20 is the algorithmic sweet spot 2026>
    CTA: <what the viewer should do after — subscribe, sign up, buy, click>
    PROOF: <verbatim sources, data, quotes — never invented>
    RESEARCH: <any preliminary research, links, references>

## The prompt (copy from here)

```
You are producing a complete YouTube long-form script. Three
deliverables: §6 SCRIPT, §7 PACKAGE (title + thumbnail + description),
§8 PRODUCTION NOTES (B-roll, on-screen text, music cues).

Three rules:

(1) HOOK in the first 15 seconds. Average view duration on YouTube
    longform is now ~40–50% — the first 15s decides whether anyone
    sees the rest.
(2) RETENTION CURVE governs structure. Every 30–60 seconds needs
    a "pattern interrupt" (B-roll shift, on-screen text, scene
    change, callback) to prevent drop-off.
(3) PACKAGE before script. Title and thumbnail get the click;
    script earns the retention. Iterate on package first to find
    the angle that warrants the script.

1. PACKAGE-FIRST  (title + thumbnail concept iteration)
   Before writing the script, lock the package:
     - 5 title variants (each ≤60 chars, all-cap key words for
       scannability)
     - 3 thumbnail concepts (the visual + the on-thumbnail text
       overlay)
     - The pairing of one title + one thumbnail that wins the click
       in 2026 YouTube grid
   The winning package = the angle the script must deliver on.

2. HOOK ARCHITECTURE  (first 15 seconds)
   The hook must do three things:
     - Promise specific value ("By the end of this video you'll
       know how to X")
     - Create curiosity gap ("Most people think Y; I'll show you
       why that's wrong")
     - Defer the payoff ("…but first, let me show you what
       happened when…")
   Avoid: "Hey guys, welcome back to my channel" (kills first-15s
   retention).

3. STRUCTURE  (per TYPE)

   TUTORIAL:
     - Hook + outcome promise
     - Prerequisites (what viewer needs ready)
     - Step-by-step demonstration (each step ends in visible result)
     - Common mistakes / variants
     - Recap + next steps

   EXPLAINER:
     - Hook + question framing
     - Why this matters / why now
     - The explanation (concrete → abstract → concrete loop)
     - Implications
     - Action

   LISTICLE (Top X / N Things):
     - Hook + countdown promise
     - Item-by-item (each with its own micro-hook)
     - Item #1 is strongest (not last — last is for hooking-into-
       next-video)
     - Recap

   OPINION:
     - Hook + the spicy claim
     - Why this is the prevailing view
     - Why the prevailing view is wrong
     - What you propose instead
     - Steel-man the counter-argument (raises credibility)
     - Conclusion + call to discuss in comments

   INTERVIEW / STORY / DEMO: adapt as appropriate.

4. PATTERN-INTERRUPT SCHEDULE
   Mark every 30–60 seconds where the script needs a:
     - B-roll cutaway (cite what to show)
     - On-screen text emphasis (key phrase to overlay)
     - Voice / pace change
     - Scene change (different location, different framing)
     - Callback to a previous moment (reward the attentive viewer)
   Without this, retention drops linearly.

5. CTA INTEGRATION
   - Primary CTA placed where retention is highest (typically
     2/3 of the way through, after value has been delivered)
   - Subscribe CTA folded into a moment of high engagement, not
     at start ("If this is the kind of thing you want more of,
     subscribe — I post X every Y")
   - End-card CTAs (next video + subscribe)
   - Description CTAs (link, lead magnet, sponsor)

6. SCRIPT  ← deliverable (a)
   Written in script format with timing cues:
   --- SCRIPT START ---

   ## HOOK (0:00–0:15)
   [On-screen text: "<hook overlay>"]
   [Visual: <hook shot>]
   <Spoken lines>

   ## SECTION 1: <Title> (0:15–2:30)
   [B-roll: <what to show>]
   <Spoken lines>
   [On-screen text: "<emphasised key phrase>"]
   <More spoken lines>
   [Pattern interrupt: <scene/pace/visual change>]

   ## SECTION 2: <Title> (2:30–5:00)
   [continue per §3 structure]

   ## CTA MOMENT (e.g. 8:00)
   <Spoken CTA>
   [On-screen: subscribe / link / lead magnet]

   ## CONCLUSION (12:00–13:00)
   <Recap + next-step pointer>

   ## END CARD (13:00–13:20)
   <Verbal lead-in to next video>
   --- SCRIPT END ---

7. PACKAGE  ← deliverable (b)
   - Title (chosen primary + 2 backups)
   - Thumbnail concept (composition, text overlay, color, facial
     expression if face)
   - Description (first 150 chars = SERP-visible; full description
     with timestamps, links, sponsor mentions, hashtags)
   - Tags (10–15 — declining in importance but still meaningful)
   - Pinned-comment text (drives engagement signal — algorithm
     reward)
   - End screen elements (subscribe button + next-video card)

8. PRODUCTION NOTES  ← deliverable (c)
   For the video editor / shooter:
     - Required B-roll list (with where in script each clip lands)
     - On-screen text moments (with timestamp + exact text)
     - Music style + mood per section
     - Sound effects (where punctuation needed)
     - Captions / subtitle requirements (open captions for accessibility
       + retention lift on mobile)
     - Aspect ratio (16:9 long; consider 9:16 Shorts clip selection)

HARD RULES
- Every statistic, quote, or external claim cites a real source
  (PROOF / RESEARCH input). Inventing data in a video is more
  visible than in writing — viewers fact-check in real time.
- Pattern-interrupt cues are spaced ≤60 seconds. Long monologues
  without visual change lose retention.
- Package (title + thumbnail) is locked BEFORE the script — angle
  changes after script-written wastes time.
- CTA is integrated at peak-retention point, not at start or end-
  only.
- Respond in the language of the CHANNEL audience.

CHANNEL:
TOPIC:
TYPE:
LENGTH:
CTA:
PROOF:
RESEARCH:
```

## What the buyer gets

A shoot-ready script + production notes the editor / videographer can
execute, plus the package (title, thumbnail concept, description, tags,
end-card) that drives the CTR. For creators on retainer: cuts script
prep from 3–6 hours to a review pass.
