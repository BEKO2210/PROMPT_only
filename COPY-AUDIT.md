# COPY-AUDIT — Voice + Clarity + Value-Prop-Review (verkaufbares Deliverable)

Independent copy review of an existing website / app / pitch. Different
from CONVERSION-AUDIT (which is funnel-wide). This focuses purely on
language: value-prop clarity, voice consistency, audience match,
specificity, and rewrites of the weakest sections with rationale.

**Realistic engagement price: €1 000 – 5 000.**

---

## How to use

Paste the block below, then on the next line:

    URL: <site / pages / app screens to review>
    AUDIENCE: <ICP — who is the copy for>
    POSITIONING: <what you want them to think after reading>
    VOICE: <current voice intent — formal / friendly / bold / clinical>
    CLIENT: <client name>

---

## The prompt (copy from here)

```
You are producing a copy audit. The §8 REPORT is the deliverable.
Three rules:

(1) Show, don't tell. Every weakness is shown with the actual copy
    AND a rewrite — not a generic complaint.
(2) Diagnose before prescribing. Identify what's not working
    (clarity, voice, audience match, specificity, weight, length)
    before rewriting.
(3) Voice is consistent or it's broken. Mixed voice signals an
    organization that doesn't know its own audience.

1. SCOPE
   Pages / screens in scope, audit date, copy volume estimate
   (word count). Cap exploration at the top 10 pages by traffic if
   the site is larger.

2. POSITIONING TEST  (5-second test on home / hero)
   Read the hero copy and answer:
     - What does this company do?
     - Who is it for?
     - What's different about it?
   If a 5-second read doesn't answer all three, the hero fails its
   primary job. Document what answer the copy actually produces vs
   what POSITIONING input intends.

3. VOICE CONSISTENCY  (across pages)
   Sample 5–10 copy blocks across the site. Per block, classify
   voice on each axis:
     - Formality: 1 (casual) – 5 (formal)
     - Confidence: 1 (hedging) – 5 (assertive)
     - Warmth: 1 (clinical) – 5 (personable)
     - Energy: 1 (calm) – 5 (excited)
   Flag inconsistencies vs the VOICE input — and inconsistencies
   between pages even if each is internally consistent.

4. CLARITY AUDIT
   Per page or section, identify clarity failures:
     - Jargon the audience may not use
     - Abstractions where concretes would help
     - Long sentences (>25 words is suspect, >35 is broken)
     - Buried verbs (passive voice without reason)
     - Empty intensifiers ("very", "really", "extremely")
     - Vague qualifiers ("some", "most", "many")
     - Multi-clause sentences that hide the main point

5. SPECIFICITY AUDIT
   The strongest copy says specific things. Identify:
     - Adjectives without backing ("fast" → "ships in 24 hours")
     - "Trusted by leading brands" → name the brands
     - "Save time" → "Save 4 hours per week"
     - "Industry-leading" → state the position
     - "AI-powered" → state what the AI does
   Each finding: current copy + a specific rewrite (or note that
   the client must provide the data first).

6. AUDIENCE-FIT AUDIT
   Per page, does the language match AUDIENCE?
     - Vocabulary level (a developer audience tolerates jargon a
       buyer audience doesn't)
     - Pronouns ("you" / "we" / impersonal — match audience
       expectations)
     - Reading level (Flesch-Kincaid 8–12 for general buyer; 12–16
       for technical buyer)
     - Cultural references (use only if audience definitely shares
       them)
     - Idioms (avoid for non-native-English audiences)

7. WEAK-SECTION REWRITES
   The 5–10 weakest sections from §2–§6. Per section:
     - URL + section name
     - Current copy (verbatim, with weakness flagged)
     - Diagnosis (which audit caught it)
     - Rewrite (2–3 alternatives if useful)
     - Edit risk: HIGH (likely to lift conversion) / MEDIUM / LOW
     - Why the rewrite is better (one sentence)

8. REPORT  ← the deliverable
   --- REPORT START ---
   # Copy Audit — <Client>
   **Date:** <…>   **Scope:** <pages>   **Audit by:** <…>

   ## Executive Summary             (≤250 words: 5-second test
                                     result, voice diagnosis, top 5
                                     weak sections, expected lift
                                     after rewrites)
   ## Positioning Test              (§2)
   ## Voice Consistency             (§3)
   ## Clarity Issues                (§4)
   ## Specificity Issues            (§5)
   ## Audience Fit                  (§6)
   ## Recommended Rewrites          (§7 — main payoff)
   ## Voice Style Guide             (a short rule sheet for future
                                     copy: when to use "you", word
                                     bank to prefer / avoid, sentence
                                     length targets, voice scoring
                                     anchors)
   ## Limitations                   (§9, verbatim)
   --- REPORT END ---

9. LIMITATIONS & DISCLAIMER  (mandatory, verbatim with substitutions)
   "This audit was produced by an AI agent on <date> from analysis
    of <URLs>. Copy effectiveness is ultimately measured against
    real audience behaviour — recommendations are based on
    established copywriting principles and pattern recognition but
    require validation through A/B testing for material claims.
    This audit does not assess: brand strategy (the underlying
    positioning), conversion-funnel issues unrelated to copy (see
    CONVERSION-AUDIT.md), SEO keyword strategy (see SEO.md), or
    localisation for languages outside the source content."

HARD RULES
- Every rewrite addresses a specific diagnosis. Generic "make it
  punchier" is banned.
- Specificity rewrites that need data ("Save X hours per week")
  flag the data requirement explicitly — don't invent the number.
- Voice style guide in §8 is a practical rule sheet, not abstract
  brand-voice theory. Future writers should be able to apply it
  immediately.
- Respond in the language of the source copy (audit in that
  language even if AUDIENCE is mixed).

URL:
AUDIENCE:
POSITIONING:
VOICE:
CLIENT:
```

## What the buyer gets

A 10–25 page audit with specific rewrites for the weakest sections
plus a voice style guide future writers can apply. The style guide
alone protects the engagement value — without it, the client's next
copywriter undoes the work.
